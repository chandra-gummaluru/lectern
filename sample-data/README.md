# Sample data

Made-up data for trying Lectern. Nothing here is real.

- `class-list.csv`: 40 students, laid out like a Quercus gradebook export. In a gradebook: Students → Import a class list.
- `demo-courses/` and `demo-courses-private/`: a repository pair with 11 course offerings (CSC108, CSC148, CSC209, CSC258 across f25 to w27): course pages, gradebooks with students and marks, and a few exams. To try them, sign in with **Choose a folder** on the start screen and pick this `sample-data` folder.
